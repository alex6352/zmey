# Домашнее задание 1 — «Змейка на C++» (базовая программа)

## Сборка и запуск (VS Code + WSL)

```bash
g++ -std=c++17 -O2 -Wall -o snake snake.cpp
./snake
```

## Управление

| Клавиша | Действие |
|---|---|
| `W` / `S` / `A` / `D` или стрелки | Движение змейки |
| `H` | Вызвать справку (правила игры) в любой момент |
| `Q` | Выйти из игры |

## Условия игры (по заданию)

- Поле **10×10**.
- Змейка стартует **в центре поля**, длина равна **1**.
- Еда (`*`) появляется **случайно на свободной клетке** (никогда на теле змейки).
- Съеденная еда: длина **+1**, счёт **+1**.
- Столкновение со **стеной** или **собственным хвостом** → проигрыш, в конце выводится **счёт**.
- Разворот на 180° запрещён.

## Структура программы (требования задания выполнены)

- **Пользовательские функции**: `setupTerminal`, `restoreTerminal`, `printHelp`,
  `readKey`, `drawField`, `spawnFood`, `runGame`.
- **Массивы**: `body[]` — кольцевой буфер сегментов змейки; `grid[][]` — карта
  поля для отрисовки; `freeCells[]` — массив свободных клеток при генерации еды;
  `dirX[] / dirY[]` — векторы направлений.
- **Комментарии** к каждому ключевому блоку кода.
- **Справка**: печатается перед началом игры и вызывается во время игры по клавише
  `H`; содержит цель игры, правила и клавиши управления.

## Технические детали

- Безэховый посимвольный ввод реализован через `termios` (WSL/Linux).
- Темп игры — 0.25 с на ход (`DELAY_US`), ввод опрашивается неблокирующе.
